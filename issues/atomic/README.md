# Loom MVP 原子 Issue

这些 Issue 是 M0–M8 模块 Issue 的下一层拆分。每个 Issue 只承担一个可以被复用、校验或独立回归的抽象边界：文件信封、语义图、坐标空间、能力协商、命令事务等。

## 拆分规则

- 业务模块只提供上下文；原子 Issue 定义一个名词或一个事务边界。
- 每个 Issue 默认适合一次 Agent 工作周期，不同时承担多个跨层结果。
- Issue 正文描述问题、当前状态、期望行为和验收，不预先规定具体库或代码结构。
- 依赖先用稳定的 `M#-##` key 表达；远端创建后再回写真实 Issue 编号。
- 所有原子 Issue 都是现有模块 Issue 的直接 Sub-issue，不改变 MVP Parent 的层级。
